## Verification scope

Findings do not print secret values. A clean clone and its remote HEAD are verified after upload.

This publication preparation does not retrain models, rerun the scientific study or imply that historical test/rebuild records were executed on today's publication commit. Original measured results and their provenance remain in the existing evidence records. GitHub source publication does not deploy a web application, run cloud services or establish production impact.
